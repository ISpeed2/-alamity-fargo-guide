# Calamity × Fargo’s — пять классов

Сайт: [открыть гайд](https://ispeed2.github.io/-alamity-fargo-guide/).

Публичный гайд по сборке: Calamity 2.2.4, Souls 1.7.3.9, Mutant 3.3.6.7, Crossmod 1.2.0.28, tModLoader 2026.8.3.0. Сложность: **Мастер + Мазохист**, соло и мультиплеер.

## Как пользоваться

Кнопка **«↑ К этапам»** появляется при прокрутке и возвращает к выбору этапа игры. В памятке закреплены кнопка **«↑ К началу»** и список перехода к любому этапу.

**Каждая строка — оружие, броня и аксессуары ДО первого убийства указанного босса.** На предмет можно нажать: откроются получение, рецепт и станция. Крылья вынесены отдельно под активный в сборке дополнительный слот. Дополнительный слот эксперта принимает только экспертные аксессуары: туда вынесен щит Ктулху. После Стены плоти используй Сердце демона для седьмого обычного слота.

Отмечай уже пройденные боссы и события. Фильтр «Доступны по прогрессу» показывает комплекты, чьи условия по победам отмечены. Компоненты, продавцов и станции по-прежнему нужно подготовить в игре.

Кнопка **«Памятка по этапам»** открывает отдельное окно: 22 этапа и 39 пунктов подготовки, постоянные бонусы шиммера, здоровье до 600, мана до 380, расходники ярости/адреналина и дополнительные слоты. Указаны актуальные названия, рецепты и станции из сборки. Отметки сохраняются отдельно в каждом профиле и включаются в скачиваемый прогресс. Старые файлы прогресса продолжают загружаться и сохраняют отметки новой памятки.

После использования **Договора Мутанта** отметь соответствующий пункт: один подходящий аксессуар в комплектах после Культиста будет перенесён в отдельный слот. В освободившийся обычный слот будет добавлен конкретный дополнительный аксессуар. Договор принимает усиления, эссенции, силы и души; обычные аксессуары в него не помещаются. Отметка убийства Культиста сама по себе не означает, что Договор съеден.

В каждой карточке под аксессуарами доступна «Перековка оружия и аксессуаров у гоблина»: защита, урон, классовые альтернативы и модификаторы оружия. В памятке после армии гоблинов собраны рекомендации сразу для всех пяти классов. Названия соответствуют русификатору сборки; для мага, разбойника и бонуса удачи учтены изменения Calamity 2.2.4. Указаны различия между посохами призыва и хлыстами и ограничения отдельных видов оружия.

Получение предмета и состав крафта учитывают версии архива, включая Remnants и мод совместимости. В раскрытии предмета оставлена одна ссылка на страницу конкретного предмета: Calamity и Fargo для модовых вещей, Terraria Wiki для ванильных. Изменённые рецепты и ограничения сборки приведены в самой карточке. В памятке ссылки убраны у обычных шагов подготовки.

В каждом режиме есть 340 карточек (680 всего), пять классов, 66 боссов/событий и 336 уникальных предметов/комплектов. Учтены изменённые ванильные рецепты, включая магматит для Огненной рукавицы и очищенный гель для Грани ночи. Ссылки карточек ведут на официальные вики предметов. Измерения лучшего урона и проверки всех боёв в игре не проводились. Подробности проверки — `AUDIT.md`, разбор десяти видео — `VIDEO-REVIEW.md`, дроп и находки — `ACQUISITION.md`, крылья и усиления — `ACCESSORIES.md`, результаты автоматической проверки — `VALIDATION.json`.

## Открыть

Открой `index.html` в браузере. Зависимостей и сборки сайта нет. Локальный сервер при желании:

```sh
python3 -m http.server 8000 --directory /Users/ispeed/Desktop/Gayd/calamity-guide
```

Адрес: http://localhost:8000. Прогресс хранится в этом браузере и для этого адреса. При переезде на GitHub Pages перенеси его через «Скачать прогресс» / «Загрузить прогресс». Профиль «С друзьями» отдельный, но не синхронизируется автоматически между людьми.

## Опубликовать на GitHub Pages

1. Создай **публичный** репозиторий, например `calamity-fargo-guide`.
2. Загрузи в корень все файлы из готового архива сайта, включая `ACQUISITION.md`, `VIDEO-REVIEW.md` и остальные отчёты.
3. Открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
6. Дождись публикации. Адрес будет `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

[Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

Архив модов и `.tmod` файлы в репозиторий не нужны.

## Редактирование

Содержимое сайта лежит в `data.js`, логика фильтров — в `app.js`, оформление — в `styles.css`.

Локальная папка `tools/` содержит инструменты чтения и проверки рецептов и исключена из Git. Она не нужна для публикации. Локальные команды повторной сборки и проверки данных:

```sh
python3 calamity-guide/tools/rebuild_guide.py
python3 calamity-guide/tools/validate_guide.py
```

При обновлении данных сохраняйте принцип комплектов до первого убийства босса: его собственный дроп и материалы следующих этапов не должны попадать в подготовку. Новые версии модов требуют повторной проверки рецептов, дропа и совместимости эффектов.

Режим «С друзьями» меняет экипировку: воин-защитник повышает агрессию, остальные классы усиливают урон и поддержку. Для команды без защитника подходят соло-комплекты. Агрессия не гарантирует постоянную цель босса. Маршрут финала — Экзо-механизмы → Каламитас; финальная броня требует материалы обоих и Вечную энергию с Мутанта. Расколотое сообщество доступно через эксгумацию у Каламитас, с обычным Сообществом одновременно не надевается.

Для повторного Натиска всем классам доступна необязательная замена классовой Души на Душу вечности. В Crossmod для её крафта нужен Камень за завершение первого Натиска. В оружейной колонке всех карточек показана краткая перековка; подробности и исключения — в разделе гоблина.

В конце карточки есть **«После победы»**: изменения оружия, брони и аксессуаров для следующего этапа и кнопка открытия его комплекта. Сравнение учитывает выбранный режим и отметку Договора Мутанта. Раздел **«Если не выпало или не нашлось»** предлагает необязательные замены с объяснением получения и компромисса. Замены не занимают дополнительные слоты.
