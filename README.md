# Calamity × Fargo’s — пять классов

Сайт: [открыть гайд](https://ispeed2.github.io/-alamity-fargo-guide/).

Гайд для сборки пользователя: Calamity 2.2.4, Souls 1.7.3.9, Mutant 3.3.6.7, Crossmod 1.2.0.28, tModLoader 2026.8.3.0. Режим со слов пользователя: **Мастер + Мазохист**, соло и мультиплеер.

## Как пользоваться

**Каждая строка — оружие, броня и аксессуары ДО первого убийства указанного босса.** На предмет можно нажать: откроются получение, рецепт и станция. Крылья вынесены отдельно под активный в сборке дополнительный слот. Дополнительный слот эксперта принимает только экспертные аксессуары: туда вынесен щит Ктулху. После Стены плоти используй Сердце демона для седьмого обычного слота.

Отмечай уже пройденные боссы и события. Фильтр «Доступны по прогрессу» показывает комплекты, чьи условия по победам отмечены. Компоненты, продавцов и станции по-прежнему нужно подготовить в игре.

Есть 340 карточек, пять классов, 66 боссов/событий и 261 уникальных предметов/комплектов. Измерения лучшего урона и проверки всех боёв в игре не проводились. Подробности проверки — `AUDIT.md`, результаты автоматической проверки — `VALIDATION.json`.

## Открыть

Открой `index.html` в браузере. Зависимостей и сборки сайта нет. Локальный сервер при желании:

```sh
python3 -m http.server 8000 --directory /Users/ispeed/Desktop/Gayd/calamity-guide
```

Адрес: http://localhost:8000. Прогресс хранится в этом браузере и для этого адреса. При переезде на GitHub Pages перенеси его через «Скачать прогресс» / «Загрузить прогресс». Профиль «С друзьями» отдельный, но не синхронизируется автоматически между людьми.

## Опубликовать на GitHub Pages

1. Создай **публичный** репозиторий, например `calamity-fargo-guide`.
2. Загрузи в корень распакованные файлы из готового архива сайта: `index.html`, `styles.css`, `app.js`, `data.js`, `favicon.svg`, `.nojekyll`, `.gitignore`, `README.md`, `AUDIT.md`, `VALIDATION.json`, `pack-info.json`.
3. Открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
6. Дождись публикации. Адрес будет `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

[Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

Архив модов и `.tmod` файлы в репозиторий не нужны.

## Редактирование

Содержимое сайта лежит в `data.js`, логика фильтров — в `app.js`, оформление — в `styles.css`.

Локальная папка `tools/` содержит инструменты чтения и проверки рецептов и исключена из Git. Она не нужна для публикации. Локальные команды повторной сборки и проверки данных:

```sh
python3 calamity-guide/tools/rebuild_guide.py
python3 calamity-guide/tools/validate_guide.py
```

Не возвращай генератор первого варианта: он использовал строки «после босса» из исходника. Текущий генератор работает с проверенными наборами до боя. Исходный HTML пользователя не изменён.
